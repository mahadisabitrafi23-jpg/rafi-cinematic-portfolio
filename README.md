# Rafi — Cinematic Editorial Portfolio

A Python-powered portfolio site built with Streamlit. The interface is styled with CSS embedded in `app.py`; no React or JavaScript is required.

## Run locally

1. Install Python 3.10+ from https://www.python.org/downloads/
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

On Windows, if `python` isn't recognized, try `py` instead.

## Personalize

At the top of `app.py`, update `NAME`, `ROLE`, `EMAIL`, `LOCATION`, and `INTRO`.
Then update the sample project descriptions and skills. Use real links and real work; remove anything that doesn't represent you.

## Publish online for free with Streamlit Community Cloud

1. Create or sign in to a GitHub account: https://github.com/
2. Create a **public** repository, for example `rafi-portfolio`.
3. Upload `app.py` and `requirements.txt` to the repository root.
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Choose **Create app**, select your repository, branch (usually `main`), and main file path `app.py`.
6. Deploy. Streamlit will install packages from `requirements.txt` and provide a public URL.

Check the deployed website and test the email link on both desktop and mobile.

## Notes

- This is a portfolio starter, not a finished professional biography. Replace all sample projects with your actual work before sharing it.
- The Google Fonts import requires internet access; fallback fonts will be used if it cannot load.
- A free hosting service may sleep or have usage limits depending on its current policy.
